# Kyros 0.6.2

This patch makes the app's screens more consistent with the Dashboard and easier
to use on narrow phones and wider displays.

- Content now uses consistent page widths, spacing, and safe-area handling across
  the tabs and nested screens.
- Transaction history filters and lists align with the rest of the page layout.
- Category, recurring payment, and budget status colors now follow the selected
  light or dark appearance.
- Crowded action and status rows wrap on smaller screens.
