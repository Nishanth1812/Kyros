Kyros 0.3.0 · Budgets and progress

- **Monthly budgets.** Set one recurring monthly limit for all expenses and/or
  separate monthly limits for individual expense categories from the new Budgets
  tab. A saved limit repeats each calendar month; there is no rollover, alerts,
  or per-month editing. Only expense categories can have a category budget.
- **Current-month progress.** See spent, remaining, and — when spending exceeds
  a limit — the exact over-budget amount for every saved limit. Progress is
  derived from your saved expense transactions dated in the current local
  calendar month (first through last day, inclusive). Income is never counted,
  and actual totals are never stored as a second balance.
- **Safe money math.** Limits are stored as positive integer paise and spending
  uses checked integer addition, so no rounding or floating-point money is
  involved. With no expenses, spent is zero and the full limit remains.
- **Safe upgrade.** Existing data is migrated in place from SQLite schema v2 to
  v3 in one transaction that adds budget storage and leaves every transaction
  and category row unchanged; a failure rolls back completely. Fresh installs
  create v3 directly. 0.1 databases still migrate through v1-to-v2 first, in the
  same transaction.
