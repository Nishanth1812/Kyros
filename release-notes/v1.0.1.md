# Kyros 1.0.1

- Simplifies the Dashboard and moves backup and export tools to Settings → Data Safety.
- Adds category editing to the Add screen, including renaming and deleting built-in categories. Deleting a category reassigns its transactions and recurring schedules and removes its category budget.
- Improves category action icons and amount visibility in dark mode.
- Keeps edited built-in categories intact when restoring current backups. V1 backups remain supported.

This release retains SQLite schema v4. Install over the previous signed release to preserve on-device data, and keep a current backup before upgrading.
