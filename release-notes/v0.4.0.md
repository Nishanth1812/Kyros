Kyros 0.4.0 · Local data safety and quality

- **User-controlled local backup and restore.** Safely export and restore all
  stored transactions, categories, and budgets using Android's native Storage
  Access Framework. Backups are exported as clean, human-readable, and
  schema-versioned JSON files without requiring external cloud accounts or network
  access.
- **Atomic, rollback-safe restore.** Backup payloads are strictly validated for
  valid structure, schema version, category relationships, and positive integer
  paise before any database modifications occur. Restore operations execute
  within a single SQLite transaction: either all records restore cleanly, or the
  existing database remains completely untouched.
- **Explicit restore confirmation.** Restoring displays a clear confirmation dialog
  previewing the backup's export timestamp and record counts (transactions,
  categories, and budgets), warns that on-device records will be replaced, and
  offers to create a backup of current data first.
- **Dedicated Data tab.** A new 5th tab on the navigation bar provides an overview
  of stored records (total transactions, income/expense breakdown, categories,
  and budgets) alongside accessible Export and Restore actions.
- **Application-wide accessibility & quality.** Interactive buttons, filter chips,
  and category pickers adhere to a minimum 48×48 dp touch target standard. Screen
  reader support has been enriched with descriptive accessibility roles, labels,
  hints, and resilient layout scaling for large display fonts.
