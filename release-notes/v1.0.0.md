# Kyros 1.0.0

Kyros 1.0 is the stable release of the local-first Android finance app. It brings
together tools for recording and organizing income and expenses, reviewing
analytics, managing budgets and savings goals, scheduling recurring transactions,
and exporting or restoring local data, with the 1.0 interface and navigation
improvements.

- Financial data stays on the device in SQLite (schema v4). The app works offline
  and does not require an account, cloud sync, network service, or backend.
- Amounts are stored as integer paise and displayed in Indian rupees.
- The savings rate shows a negative percentage when expenses exceed income and
  "Not available" when there is no income; Dashboard and Analytics charts show
  readable scales, exact values, and accessible labels.
- A dedicated Settings screen holds the system, light, and dark appearance
  choices. The five bottom tabs are unchanged, and secondary screens return with
  the in-app back action or Android system Back.
- Local JSON backups and CSV transaction exports are available from the Data tab.
  New JSON backups record the app version that created them (1.0.0); older V1
  backups remain restorable.
- Interactive controls use a shared 48 dp minimum target with descriptive
  accessibility labels.
- Installing over 0.6.2 preserves saved data when the APK uses the same signing
  key. Android 7.0 (API 24) or later is required.

Version code: `13`.
