# Kyros 1.0.0

Kyros 1.0 is the stable release of the local-first Android finance app. It brings
together the existing tools for recording and organizing income and expenses,
reviewing analytics, managing budgets and savings goals, scheduling recurring
transactions, and exporting or restoring local data.

- Financial data stays on the device in SQLite. The app works offline and does
  not require an account or cloud service.
- Amounts are stored as integer paise and displayed in Indian rupees.
- Local JSON backups and CSV transaction exports are available from the Data tab.
- Installing over 0.6.2 preserves saved data when the APK uses the same signing
  key.

Version code: `13`.
