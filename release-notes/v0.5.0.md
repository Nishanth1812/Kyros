Kyros 0.5.0 · Enhanced analytics and visuals

- **Historical month navigation.** Review past earnings and expenses with previous
  and next month navigation directly on the Dashboard. Totals and category
  breakdowns recalculate dynamically for any selected calendar month, with a
  one-tap shortcut to return to the current month.
- **Visual category spending distribution.** See proportional spending distribution
  across categories with a segmented visual bar and a ranked breakdown showing
  exact amounts and percentages.
- **Multi-month spending & income trends.** Explore financial trajectories over the
  last 6 months with an accessible paired bar chart comparing income and expenses.
- **Dedicated Financial Analytics screen.** Open full insights from the Dashboard to
  review daily average spending, savings rate, top spending category, and historical
  trends.
- **CSV spreadsheet report export.** Export your complete transaction history to a
  standard RFC 4180 comma-separated (`.csv`) spreadsheet file via Android's native
  Storage Access Framework in the Data tab.
- **Accessible & zero-dependency.** Built cleanly with React Native core components
  without adding third-party chart libraries, maintaining ≥ 48×48 dp touch targets
  and comprehensive screen reader summaries.
