This update moves Kyros to standard React Native on Android. You can still add and view income and expenses offline.

## What changed

- Removed Expo from the Android app and development workflow.
- Switched to Android’s built-in SQLite driver. Kyros opens the same transaction database during an in-place update.
- Updated the release workflow to reuse Gradle build outputs and attach the verified APK directly to GitHub Releases.

## Install or update

Download `kyros-v0.1.2.apk` from **Assets** below. On Android 7.0 or newer, install it over your existing signed Kyros release to keep your transactions. Android requires updates to use the same signing key as the installed app.

Android versionCode: `3`.
